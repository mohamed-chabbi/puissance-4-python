# Puissance 4 (Connect Four)

A Python implementation of the classic **Connect Four** game using **Tkinter**.

## 🎮 About

Puissance 4 is a two-player strategy game played on a 6×7 grid. Players take turns dropping their pieces into columns. The first player to connect four pieces horizontally, vertically, or diagonally wins.

## ✨ Features

- Human vs Human gameplay.
- Interactive graphical interface built with Tkinter.
- Automatic detection of winning combinations.
- Draw detection when the board is full.
- New Game option.
- Game move history.

## 🛠️ Technologies

- Python
- Tkinter

## 🚀 Getting Started

### Prerequisites

- Python 3.x
- Tkinter

### Run the game

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/puissance-4-python.git
cd puissance-4-python
```

Run the application:

```bash
python puissance4_gui.py
```
